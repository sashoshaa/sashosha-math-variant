# SashoshaMath (MVP-прототип)

Онлайн-тренажёр по математике для учеников **5–9 класса** с акцентом на **СДВГ** и трудности концентрации: спокойный интерфейс, адаптивный темп, несколько попыток на задание и **прототип** личного кабинета с оплатой на сайте.

Оригинальная версия: [github.com/sashoshaa/sashosha-math](https://github.com/sashoshaa/sashosha-math)

## Что нового в этом клоне

- **Режим СДВГ** — крупнее элементы, фокус-режим, паузы, мягкие подсказки.
- **Адаптация** — учитывает время ответа, попытки и ошибки; меняет длину серии и сложность.
- **Личный кабинет (демо)** — имя, класс, статистика; данные в `localStorage`.
- **Подписка (демо)** — 300 ₽/мес и 3 600 ₽/год без реального списания; открывает все 13 тем.
- **Бесплатно** — только «Таблица умножения» (первый уровень).

## Запуск локально

```bash
cd /Users/sashosha/Projects/sashosha-math-variant
python3 -m http.server 8080
```

Открой [http://localhost:8080](http://localhost:8080)

Telegram-бот из `bot.py` — как в оригинале, для воронки с каналом. Сайт можно использовать отдельно.
